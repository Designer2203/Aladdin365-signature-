Add the signature to Gmail
  1. Click Copy signature above.
  2. In Gmail, open Settings (gear) → See all settings → General → Signature.
  3. Click Create new, name it, then click inside the editor and paste (Ctrl + V / ⌘ + V).
  4. Set it as the default for new emails and replies, scroll down and click Save changes.
Add the signature to Outlook
  1. Outlook on the web / new Outlook: Settings → Account → Signatures → New signature, paste, then Save.
  2. Outlook desktop (classic): File → Options → Mail → Signatures → New, paste into the editor, then OK.
  3. If Outlook pastes it without layout, use Copy HTML code instead and ask IT to install it as an .htm signature file.
